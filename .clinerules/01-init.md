# init フェーズ

> 前提として `00-overview.md` の共通仕様・共通ルールを必ず参照すること。

## このフェーズでやること

- プロジェクトの初期化
- Supabase (Database / Storage) との接続設定
- Expo の初期化
- ビルドを通す
- Git の初期化

## 実装上の注意

- このフェーズでは画面や機能（写真アップロード、リアクションなど）は実装しない。あくまで基盤構築のみ。
- 仕様書に書かれていること以外は実装しない。
- 実装する前に、どのファイルを変更するのかを必ず確認すること。
- 動作確認は `build` のみとする。実機確認は行わない。Webでの確認も不要。
