# DIRECTLY. — 直接のつながりを、もっと

離れて暮らすおじいちゃん・おばあちゃんと孫をつなぐ、写真共有アプリです。
孫が写真を送り、おじいちゃんが「Good」を返す。この毎日のやりとりが、そのまま**安否確認**になります。

**▶ デモ：** （公開後にURLを記載）

## 解決したい課題

一人暮らしの高齢者は、配偶者との死別や施設入居をきっかけに、人と話す機会が大きく減りがちです。
孤立は認知機能の低下や健康の悪化にもつながります。

電話やメッセージは「用事がないとしにくい」ものです。そこで、**写真を1枚送るだけ・Goodを押すだけ**という、いちばん気軽な形のコミュニケーションを毎日の習慣にすることを目指しました。

## 特徴

### 死期ゲージ —「おじいちゃんを死なせない」
画面の上に、おじいちゃんの**死期ゲージ**があります。写真やGoodのやりとりが途絶えるとゲージは少しずつ減り、やりとりをすると回復します。
たまごっちのような育成ゲームの感覚で、「今日も写真を送ろう」「今日もGoodを返そう」と思えるようにしました。

### ゲージが尽きると「走馬灯」
ゲージが0になると、アプリの中のおじいちゃんは亡くなってしまいます。それまでにやりとりした写真が**走馬灯のように流れる演出**のあと、「ReBorn」でやり直せます。
現実のおじいちゃんに会いに行きたくなる、少しだけ切ない仕掛けです。

### 日本の暦で振り返るアルバム
届いた写真は、**旧暦の月名（睦月・如月…）と伝統色**で染めたカレンダーで振り返れます。背景には和紙の質感を重ね、高齢の方にもなじみやすい、落ち着いた見た目にしました。

## 使い方（デモの試し方）

このアプリは「孫」と「おじいちゃん」の**2人で使う**ものです。1台のPCで試す場合は、**通常のウィンドウとシークレットウィンドウ**で1人ずつ開くと、別の端末として動かせます。

1. **孫として**：「グループを作成」→ 好きな合言葉（例：`demo-family`）を入力 → 自分とおじいちゃんのプロフィールを入力
2. **おじいちゃんとして**（シークレットウィンドウ）：「グループ参加」→ 同じ合言葉を選ぶ
3. 孫側で「アルバムから送信」→ 写真を選んで送信
4. おじいちゃん側で、届いた写真に「Good」を押す → 死期ゲージが回復する
5. 「アルバム」タブで、カレンダーから過去の写真を見る

※ デモ用に、ゲージを手動で増減できるボタンがあります（走馬灯の演出もすぐに確認できます）。
※ 実際の時間では1日かかる減少を、デモでは**60秒 ＝ 1日**に縮めています。

## 担当と開発の経緯

- **チーム開発**：ハッカソンで、**UI/UX を担当**しました（画面構成、画面の流れ、見た目のデザイン）
- **個人での改良**：ハッカソン後に一人で開発を続け、次のような改良を行いました
  - **旧暦カレンダーと和紙の質感**：高齢の方にもなじむよう、旧暦の月名と伝統色で染めたカレンダーに、和紙の質感を重ねた
  - **重くなりすぎない見せ方**：「死期」という重いテーマを扱うからこそ、全体はカジュアルに見えるよう工夫した
  - **走馬灯の演出**：これまでの思い出がよみがえる演出にすることで、孫側がきちんと「死」を意識できるようにした
  - **Web版への対応**：選考の方がURLを開くだけで試せるようにした（下記）

## 技術構成

| 分類 | 技術 |
|---|---|
| フロントエンド | React Native（Expo）/ TypeScript / React Navigation |
| バックエンド | Supabase（PostgreSQL / Storage / Row Level Security） |
| Web対応 | react-native-web（`expo export -p web` で静的サイトとして出力） |

API サーバーは持たず、アプリから `@supabase/supabase-js` で Supabase に直接アクセスする構成です。
死期ゲージの増減は、同時に操作されても値が狂わないよう、PostgreSQL の関数（`update_life()`）の中で行の**ロックを取ってから**計算しています。

### Web版で工夫したこと
もともとスマホ向けに作ったアプリを、選考の方が**URLを開くだけで試せる**ように Web に対応させました。
スマホ版の動きを変えないよう、`xxx.ts` と `xxx.web.ts` の**プラットフォーム別ファイル**で差分を分けています。

- **PCで開いたときの表示**：スマホ幅（430px）の枠に収めて、画面中央に表示
- **ダイアログ**：Webでは表示されない React Native の `Alert` を、ブラウザの `alert` / `confirm` で代わりに表示
- **画像のアップロード**：スマホで撮った 4000px・4MB 超の写真を、アップロード前に**長辺1600pxに縮小**（表示の粗さと読み込みの遅さを解消）
- **レイアウト**：スクロールバーが出るとカレンダーが崩れる問題を、実際の表示幅を測って配置することで解消

## ローカルで動かす

### 1. Supabase を用意する
1. [Supabase](https://supabase.com/) でプロジェクトを作成する
2. SQL Editor で `supabase/migrations/all_migrations.sql` を実行する
3. Project Settings → API から `Project URL` と `anon public` キーを控える

詳細は [`supabase/README.md`](supabase/README.md) を参照してください。

### 2. アプリを起動する
```bash
cd app
cp .env.example .env   # 控えた URL と anon キーを記入する
npm install
npx expo start --web   # ブラウザで起動（スマホは Expo Go で QR コードを読み取る）
```
